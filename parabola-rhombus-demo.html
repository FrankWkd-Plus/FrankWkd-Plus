抛物线 y = −(x−2)² + 5 与菱形 ABCD · 参数 m 动态演示

拖动滑块改变 m，观察 A、B、C、D 四点与菱形如何运动；玫红色加粗的一段是「抛物线落在菱形内部的弧」。

题目原题（按截图整理）

在平面直角坐标系 xOy 中，抛物线 y = −(x−2)² + h 过点 (0,1)。A、B 是此抛物线上不重合的两个动点，横坐标分别为 m、2−m；点 C 的横坐标为 4−3m，且 C 的纵坐标与 A 的纵坐标相等。以 BA、BC 为邻边构造 ▱ABCD。

  1. 求该抛物线对应的函数表达式。
  2. 作直线 AB，求证：直线 AB 与横轴（x 轴）所夹锐角的大小不变。
  3. 当此抛物线在 ▱ABCD 内部的点的纵坐标 y 随 x 的增大而增大、或随 x 的增大而减小时，求 m 的取值范围。
  4. 当 m < 1 时，▱ABCD 的边与直线 x = 1 的两个交点分别为 E、F；当 ▱ABCD 的边与该抛物线有交点时（▱ABCD 的顶点除外），设交点为 G，连结 GE、GF。当 △EFG 的面积是 ▱ABCD 面积的 1/4 时，直接写出此时 m 的值。

结论四个“不动”的结构（后续所有图形都由它们决定）

(1) 抛物线y = −(x−2)² + 5，顶点 E(2, 5)，对称轴 x = 2
(2) 斜率固定kAB = (4−4m)/(2−2m) = 2，锐角 arctan2 ≈ 63.4° 不变
(3) 四点坐标A(m, −m²+4m+1)、B(2−m, 5−m²)、C(4−3m, −m²+4m+1)、D(2−m, −m²+8m−3)
(4) 菱形AC 水平、BD 竖直 ⇒ AC⊥BD；中心 (2−m, −m²+4m+1)，半对角 2|1−m|、4|1−m|；S = 16(1−m)²

因为 yA = yC 恒成立、A 与 C 关于 BD 对称，所以 ▱ABCD 一定是菱形，第 (3)(4) 问的全部推理都建立在这一点上。

视野会随 m 自动缩放（m 靠近 1 时菱形很小、m ≥ 4 时很大），因此个别位置坐标轴会落到视野外而不绘制；「叠加 x = 1」只对 m < 1 有意义。

第 (3) 问“内部弧单调” ↔ “顶点 E 不在菱形内部”

抛物线在菱形内部的那一段（玫红）本身是一条曲线。y 随 x 增大而单调，等价于这一段不跨过对称轴 x = 2；而它会跨过对称轴，唯一的原因是顶点 E(2,5) 严格落在菱形内部。

① 菱形内部的判据

菱形被两条对角线“锁定”在坐标轴方向上（AC 水平、BD 竖直），所以点 (x, y) 在菱形内部等价于

|x − (2−m)| / (2|1−m|) + |y − (−m²+4m+1)| / (4|1−m|) < 1

② E 严格在菱形内部 ⟺ 2 < m < 4

把 E(2,5) 代入上式并去分母（m<1 时得 2|m| + m² < 0，无解；m>1 时化为 m² − 6m + 8 < 0）：

(m−2)(m−4) < 0 ⟺ 2 < m < 4

此区间内玫红弧分成左右两段、跨过顶点，既不单调增也不单调减，排除。

③ 另一类失效：内部弧根本不存在（0 ≤ m ≤ 1）

m = 0 时 C(4,1) 恰在抛物线上，内部弧退化成零长；m = 1 时 A、B、C、D 四点重合于 (1,4)，图形退化。而 0 < m < 1 时，在 x ∈ (m, 2−m) 上

f(x) − yAB = −(x−m)(x−2+m) > 0

即抛物弧恒在边 AB 的上方，而菱形内部在 AB 下方；x ∈ (2−m, 4−3m) 的部分又恒在边 BC 上方（BC 与抛物线的另一交点 x = 4+m 已落在菱形之外）。所以菱形内部没有抛物线上的点，条件无从谈起，同样排除。

④ 结论

m < 0　或　1 < m ≤ 2　或　m ≥ 4

说明：0 < m < 1 与 m = 1 时菱形内部无抛物线点；m = 0 时内部弧退化为一点。m = 2 时 A 与顶点 E 重合、m = 4 时 E 落在边 AD 上，这两种“相切”情形内部弧仍单调，取等号。

第 (4) 问△EFG = ¼ 菱形：m = −1/3 或 −5/3

  1. 由 (3)：AC = 4−4m，BD = 8−8m，S菱形 = ½·AC·BD = 16(1−m)²（m < 1）。
  2. x = 1 与 AB、AD 交于 E(1, −m²+2m+3)、F(1, −m²+6m−1)，相减得 EF = 4−4m，恰与 AC 等长（这一点由菱形的对称性也能直接看出）。
  3. 去掉顶点后的交点 G 只能在边 BC 或 CD 上：边 AB 与抛物线只交于 A、B；边 AD 与抛物线只交于 A（另一交点 x = 6−m 在 D 的右侧之外）。
  4. 设 G 到 x = 1 的距离为 d，由 ½·EF·d = ¼·16(1−m)² 得 d = 2(1−m)，于是 xG = 1 + d = 3−2m（另一解 2m−1 < 1 不在 BC、CD 的横坐标范围内，舍去）。
  5. G 在 BC 上：y = −2x − m² − 2m + 9，代入 G(3−2m, −4m²+4m+4) 得 3m² − 2m − 1 = 0 ⇒ m = −1/3（m = 1 舍）。
  6. G 在 CD 上：y = 2x − m² + 10m − 7，代入得 3m² + 2m − 5 = 0 ⇒ m = −5/3（m = 1 舍）。

两张图下方的比值由程序实时计算（S△EFG、S▱ABCD 均用同一套公式），可与手算对照：64/9 : 256/9 = 1/4。注意 m = −5/3 那幅图里 F 与 G 恰好同高（都等于 −124/9），△EFG 是以 EF 为竖直直角边的直角三角形。
